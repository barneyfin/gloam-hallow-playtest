# Gloam Hallow playtest

A playtest copy of **Gloam Hallow**, a game by Lantern Box Games, for friends and family to try. Not finished.

Open https://barneyfin.github.io/gloam-hallow-playtest/ and choose:

- **Play Gloam Hallow** (`gloam-hallow.html`): the game. A run is saved at each lantern, so a closed tab can carry on from the title (Continue). Since 0.33.0-r2, The Endless Rot, a mode of endless waves in small arenas, is open from the start: choose it after Start game. Since 0.35.0-r2, the game has a difficulty setting: once something is bought at the Echo Shrine (or with The Endless Rot chosen), Start game shows Shallow, Grim and Agony under the runs; The Bare Reckoning is always Grim. On Grim and Agony monsters hit harder and take more hits place by place, get a little faster with each place, drop less, and the heal spell costs more mana; the echo kept scales with the setting. The first time a device opens this version its high scores, personal bests and any saved run are cleared once (the stolen echo and everything bought stay), because the game is harder than the one those scores were made on. Since 0.33.1, the forest's leaves drift smoothly however long you've played, and on a computer the ; key beside L rolls as Shift does. Since 0.34.3, the walkers and ghouls walk on stepping legs, a walker's stooping sweep hits you standing (roll through it), a crawler's lunge or a flyer's dive no longer turns you round, and the wave's number is easier to read.
- **Speed test** (`gloam-hallow.html?check`): Start game plays by itself for about two minutes, then shows how smoothly it ran, with Email, WhatsApp and Copy to send the result (with the last 20 runs played on this device).
- **Send my runs** (`gloam-hallow.html?runs`): the last 20 runs played on this device (how far each got, the lives lost and how it ended), with Email, WhatsApp and Copy to send them. The game sends nothing by itself.

`gloam-hallow.html` is a built single-file page (made by `python lantern-box/kit/build.py gloam-hallow` in Barney's arcade). The fonts embedded in it, IM Fell English and Alegreya Sans, are under the SIL Open Font License 1.1; their licences are in `licences/`. The music was made with Google Gemini.
