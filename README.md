# Gloam Hallow playtest

A playtest copy of **Gloam Hallow**, a game by Lantern Box Games, for friends and family to try. Not finished.

Open https://barneyfin.github.io/gloam-hallow-playtest/ and choose:

- **Play Gloam Hallow** (`gloam-hallow.html`): the game.
- **Speed test** (`gloam-hallow.html?check`): Start game plays by itself for about two minutes, then shows how smoothly it ran, with Email, WhatsApp and Copy to send the result.

`gloam-hallow.html` is a built single-file page (made by `python lantern-box/kit/build.py gloam-hallow` in Barney's arcade). The fonts embedded in it, IM Fell English and Alegreya Sans, are under the SIL Open Font License 1.1; their licences are in `licences/`. The music was made with Google Gemini.
